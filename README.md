🏰 Wizard University of Arcania

**Knowledge Beyond the Stars ✨**

Welcome to **Wizard University of Arcania**, a fantasy-themed university website built using **HTML, CSS, and Bootstrap 5**. Inspired by ancient magical academies, this project brings together rich storytelling, immersive design, and responsive web development to create a prestigious institution of magical learning.

---

## 📖 About the Project

Founded in the year **1226**, Wizard University of Arcania has served as a beacon of magical knowledge for over 800 years. This website showcases the University's history, academic schools, distinguished faculty, top students, and vibrant campus life.

The project was created as a Bootstrap-based web design project to demonstrate responsive layouts, modern UI components, and creative world-building.
